# Song-Coach

Ein Claude-Projekt, das mich Schritt für Schritt vom Loop zum fertigen Song führt.

## Einrichten (einmalig, auf claude.ai)

1. *Projects* → neues Projekt **„Song-Coach“**.
2. **Projekt-Anweisungen:** den Inhalt von [`instructions.md`](instructions.md) einfügen.
3. **Projekt-Wissen:** [`studio.md`](studio.md) hinzufügen – am besten direkt aus GitHub
   (Repo `TimAH93/fummelfuerst`, Ordner `docs/song-coach`), dann bleibt es aktuell.
   Optional die FLkey-37-Anleitung (PDF) dazulegen.

## Pro Song

- Neue Datei in [`songs/`](songs/) anlegen (Vorlage: [`songs/_vorlage.md`](songs/_vorlage.md)).
- Im Projekt einen neuen Chat starten und den Song-Steckbrief einfügen
  (aus Fummelfürst → „Song-Steckbrief“ → „Für Claude kopieren“, oder aus der Song-Datei).
- Die Songkarte, die der Coach anlegt, in die Song-Datei übernehmen, damit der Stand nicht verloren geht.
